Learn to program

A course by Moisés C.

Short, interactive lessons with Python. Tap, drag and try things out: that is how you see the way a program thinks.

  • 📦

    Variables

    Boxes with names to store data, do math with it and write messages.

    See the lessons
    1. What is a variable? Boxes with names that hold a value.
    2. Formulas Math with variables: operators, parentheses, // and %.
    3. Reuse Use a variable in many places and update it: x = x + 1 and +=.
    4. Text and numbers "5" + "5" gives "55": the types int and str, int(), str() and input().
    5. Messages with f-strings print(f"Hello {name}"): values inside text, math and decimals with :.2f.
  • 🚦

    Conditionals

    Decide what to do based on a condition, and combine several questions into one.

    See the lessons
    1. if, else and elif Yes-or-no questions, the six comparison operators and choosing a path.
    2. Combining conditions and, or and not: several questions in one, and values between two numbers.
    3. Comparing text Uppercase letters, .lower(), searching with in and comparing what comes from input().
    4. Nested conditions An if inside another: decision trees, indentation and when to join them with and.
    5. Project: the ticket booth Build a movie theater ticket booth in parts: it asks, decides the price and answers.
  • 🔁

    Loops

    Repeat a task without writing it a thousand times: count, add up, decide in each round, go through text, stop in time, nest loops and draw patterns.

    See the lessons
    1. for, range and while Repeat without copy and paste: one round for each number, or while something is True.
    2. Counting and adding up range with a step, countdowns, counters and running totals with +=.
    3. Deciding in each round An if inside the loop: filtering, even or odd, counting matches and finding the record.
    4. Looping over text for letter in "hello": one round per letter, counting vowels and measuring with len().
    5. Leaving early: break and continue Stop the loop, skip a round, while True and how to avoid infinite loops.
    6. Nested loops A loop inside another: grids, multiplication tables and staircases of stars.
    7. Drawing patterns i or j?, spaces to line things up, pyramids, a hollow square and a chessboard.
    8. Project: guess the number Build, part by part, a game that thinks of a number and gives you hints until you guess it.
  • 🧩

    Functions

    Named recipes you can reuse: def, parameters, return, the functions Python already has, functions that use others, and a game made with functions.

    See the lessons
    1. def, parameters and return A recipe with a name: you define it once, call it whenever you want, and it gives you back a value.
    2. You already used them: Python's functions input, len, int, str, round, abs, max and random.randint: a value goes in and another comes out, even one inside another.
    3. Multiple parameters Pass arguments by position or by name, and parameters with a default value.
    4. Functions that decide A return on each path of the if, functions that return True or False, and why you get None without a return.
    5. Local variables A function's boxes are born when you call it and are erased when it returns; the same name inside and outside means two different boxes.
    6. Functions that use functions A function that calls another, loops inside a function, and the call stack: each return removes the top card.
    7. Project: rock, paper, scissors Build the game against the computer step by step: three small functions and a loop with a score.
  • 🎁

    Recursion

    Functions that call themselves: like opening a box that has another box inside.

    See the lessons
    1. A function that calls itself The base case, the stack that grows and empties, the RecursionError, and what happens on the way in and on the way back.
    2. Recursion that returns values factorial, power and the sum of digits: what each call returns goes down to the one below and completes its math.
    3. Digits and bases Count the digits of a number and turn it into binary or another base: the remainders are read on the way back.
    4. Call tree fibonacci calls itself twice: the tree that grows branch by branch, the calls that repeat and how many it makes in total.
    5. Printing combinations Every way to flip some coins: a decision tree where each leaf prints a combination, and branches that get pruned.
    6. Let's practice Twelve short exercises: what it prints, fill in the blank, find the bug and trace it in the table.
    7. Project: the padlock Open a padlock by trying every code: stop when you find it, and use a hint to cut branches.

    Text in depth

    Text is a row of numbered cells: read a letter, cut out a piece, transform it and search inside it.

    See the lessons
    1. Each letter in its place word[0], the last letter with len or with -1, the IndexError and going through a text with its position.
    2. Slices text[1:4] with scissors that cut between the letters: the end is left out, [:3], [3:], negatives and splitting a date.
    3. Methods that transform .upper(), .title(), .strip() and .replace(): they return a new text you have to save, and when chained, order matters.
    4. Searching in text .count(), .find() and its -1, .startswith(), .endswith() and .isdigit() to check a value before int().
    5. Project: hangman Guess a fruit letter by letter: the word with dashes, the guessed letters in a text, lives, and you win when no _ is left.

    Lists

    Many values stored in order in a single variable: read them, change them, add and remove, go through them, sort them and build grids.

    See the lessons
    1. Many values in one variable From five variables to one list: grades[0], grades[-1], len, the IndexError, changing a slot and going through it with for.
    2. Adding and removing The empty list, append, insert, pop and remove: they change the list itself (grades = grades.append(15) loses it) and filling it with input().
    3. Looping and adding up Add up, count and find the highest with a for, sum(), max(), min() and the average, filter into a new list and range(len(grades)) for the position.
    4. Sorting and searching sorted() gives a new list and .sort() changes the same one (and returns None), reverse=True, the podium with [:3], .index(), .count() and random.choice().
    5. From text to list and back .split() cuts a sentence into slots, .split(","), .strip() on each piece, .join() to glue them and several grades in one line with input().split().
    6. Two names, one list b = a doesn’t copy a list: it gives it another label. .copy() and a[:] make another one, and a function that changes a list changes it outside too.
    7. Lists inside lists A board as a list of rows: board[r] gives a row, board[r][c] a square, changing it and going through it with two for loops.
    8. Project: tic-tac-toe The board as a list of lists: board[r][c], reading row and column with .isdigit(), checking rows, columns and diagonals, turns and a tie.

    Other structures

    Tuples that don’t change, dictionaries that keep each value with its name and sets with no repeats: when each one fits.

    See the lessons
    1. A list that doesn’t change Tuples: you read them like a list but can’t change them, unpack day, month, year = date, swap a, b = b, a and return lowest, highest.
    2. Each value with its name Dictionaries: grades["Ana"] looks up by key instead of by number, the KeyError, adding and changing, del, in and .get().
    3. Looping over a dictionary for over the keys, .items() with two variables, .values() with sum() and max(), counting who passed and who has the best grade.
    4. Counting with a dictionary How many times each letter, word or vote shows up: slots are born and grow, the KeyError trap and counts.get(x, 0) + 1.
    5. Sets: no repeats and no order A bag where a repeat can’t get in: .add(), .remove(), set(list) to drop repeats, and joining and crossing with |, & and -.
    6. Structures together A dictionary of lists, a list of dictionaries and a list of tuples, and which one fits each problem.
    7. Project: the class vote Electing a class representative: the candidates in a tuple, the votes in a dictionary and who already voted in a set, so nobody votes twice.
  • 🔎

    Searching

    Finding a value in a list: look one by one or, if it is sorted, cut it in half again and again. How many comparisons each one makes.

    See the lessons
    1. Searching one by one Uncover slots until you find it: linear search with for, return i when you find it and return -1 at the end, best and worst case, and how many comparisons it makes.
    2. Searching with conditions The first failing grade, someone’s grade in two parallel lists, all the positions, the last one and searching a grid.
    3. Cutting in half Guess a number from 1 to 100 in 7 questions: look at the middle one and throw away half. It only works if the list is sorted.
    4. Binary search low, high and mid = (low + high) // 2 in a while: the pointers close in, the discarded half fades and the trace table fills up.
    5. Binary search with recursion search(items, x, low, high) calls itself with the half that is left: the call stack, the base case low > high and why a slice loses the position.
    6. Which one is faster? A race between linear and binary search with 8, 1,000 and a million values: twice the values, twice the comparisons or just one more.
    7. Project: the PC guesses your number You think of a number from 1 to 100 and the PC guesses it in 7 questions or fewer with binary search; if you cheat, it notices.
  • 📊

    Sorting

    How the PC sorts a list when it can only compare two values at a time: bubble sort, quicksort and mergesort, and which one is faster.

    See the lessons
    1. Swapping neighbors Sort slots by tapping two neighbors, swap two values with a temp box, and one pass where the highest bubbles up.
    2. Bubble sort bubble(items) with two for loops: the sorted part grows from the right, how many comparisons it makes and how to stop early if a pass changed nothing.
    3. Quicksort Pick a pivot, split into smaller and larger, and sort each part with recursion: the list breaks into pieces and comes back together.
    4. Merging two sorted lists Two piles already sorted: look at the first card of each and take the smaller one, with two pointers i and j, and don’t forget the leftovers.
    5. Mergesort Cut in half until you have lists of one value, then merge them two by two from the bottom up.
    6. Which one sorts faster? A race between bubble sort, quicksort and mergesort with 8, 100 and 1,000 values, and the cases where each one wins or loses.
    7. Project: the leaderboard Read a class’s names and grades and sort them from highest to lowest in two lists at once, with ties in alphabetical order.

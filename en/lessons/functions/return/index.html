A function with several exits

Inside a function you can use if and elif, and put a return on each path. Move the grade and find the three exits.

def rate(grade):    if grade >= 18:        return "Excellent"    elif grade >= 11:        return "Passed"    else:        return "Failed"print(rate(15))

    return ends the function

    When Python reaches a return, it hands over the value and leaves the function right away. Will “Well done!” be printed? Run it with both grades.

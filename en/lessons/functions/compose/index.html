A function that calls another

average does not add on its own: it asks add for help. Each call puts a card on top of the one before. Run it and watch the stack.

def add(a, b):    return a + bdef average(a, b):    total = add(a, b)    return total / 2grade = average(14, 17)print(grade)

Output

This tower of cards is called the call stack: only the top card works; the ones below wait.

    In how many ways can you arrange some books on a shelf? You multiply 1 × 2 × 3 × … up to the number of books. That is the factorial, and a function with a for works it out.

    def factorial(n):    result = 1    for i in range(1, n + 1):        result *= i    return resultways = factorial(4)print(f"{ways} ways")

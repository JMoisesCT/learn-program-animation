Functions 3/7 · Multiple parameters

Two values, two boxes

A function can take several values, separated by commas. Each argument in the call travels to its parameter box. Run it.

def introduce(name, age):    print(f"{name} is {age} years old")introduce("Ana", 15)

Output

Order matters

Python hands out the arguments by position: the first one to the first parameter, the second one to the second. Run it, swap the numbers, and run it again.

def subtract(a, b):    return a - b

Output

Arguments by name

If you write parameter=value, each value goes to the box you name, in any order you like. Try both ways.

def introduce(name, age):    print(f"{name} is {age} years old")

Output

Default values

A parameter can come with a default value: it is used if the call does not give it another one. Try it with and without the second argument.

def greet(name, greeting="Hello"):    print(f"{greeting}, {name}!")

Output

Parameters with a default value go at the end: the required ones come first.

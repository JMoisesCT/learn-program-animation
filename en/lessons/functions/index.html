Functions 1/7

A function is a recipe with a name

You write the instructions once and use them whenever you want by calling the function by its name. Use it several times: all at once or line by line.

def greet():    print("Hello!")    print("How are you?")

Calls: 0

📜 Recipe greet
  1. print("Hello!")
  2. print("How are you?")
Output

def only defines the recipe: it does nothing until you call it with greet().

Calling is jumping… and coming back

When you call a function, Python jumps to its code and, when it finishes, comes back to where it was. Run it line by line.

def greet():    print("Hello!")print("Start")greet()greet()print("End")

Now in: main program Calls: 0

Main program
  1. print("Start")
  2. greet()
  3. greet()
  4. print("End")
Inside greet()
  1. print("Hello!")
Output

Parameters: giving data to the function

You pass it a value inside the parentheses. Inside, the parameter name keeps it like a variable. Try two names.

name 
def greet(name):    print("Hello, " + name + "!")greet("Ana")

Output

Loops 6/8 · Nested loops

A loop inside another

The outer loop makes the rows (i); the inner one, the stars in each row (j). Move both sliders.

for i in range(3):    for j in range(4):        print("*", end="")    print()

end="" makes the next print stay on the same line. print() alone jumps to the next line.

Row by row

Watch the two boxes: for each value of i, j does all its rounds. That is how a times table fills up.

i
j 
for i in range(1, 4):    for j in range(1, 4):        print(f"{i} x {j} = {i * j}")

Where does the line break go?

The same print() with a different indentation changes the drawing. Try it in all three places.

for i in range(2):    for j in range(3):        print("*", end="")    print()

A triangle, star by star

Now the inner loop uses i: range(i + 1). Watch how many rounds j does in each row.

i –
j 
for i in range(4):    for j in range(i + 1):        print("*", end="")    print()

The small number on each star is the value of j when it was printed.

In a nested loop, for each round of the outer loop, the inner one does all its rounds.

for i in range(3):      # 3 rows    for j in range(4):  # 4 per row        print("*", end="")    print()             # new line at the end of the row

Recursion 3/7 · Digits and bases

How many digits does it have?

You can see at a glance that 4071 has 4 digits. Python can't see them: to Python, it's just a number. But it can divide: 4071 // 10 gives 407, the number without its last digit.

Number:

📜 How to count the digits of n

  1. If it has a single digit (n < 10): it has 1.
  2. If not: cut off the last one (n // 10), count the digits of what's left and add 1.

The ones that dropped off (n % 10)

One digit fewer in each call

The recipe, in Python. Each call gets the number with one digit fewer, until only one is left: the base case.

Number: 
def count_digits(n):    if n < 10:        return 1    return 1 + count_digits(n // 10)print(count_digits(4071))

Only zeros and ones

The computer stores numbers in binary: only with 0 and 1. Each place is worth double the one to its right: 1, 2, 4, 8… (in the usual system, each place is worth 10 times more: 1, 10, 100…).

The remainders of dividing by 2

How does Python turn a number into binary? Just like % 10 gave the last digit in the usual system, % 2 gives the last digit in binary. Divide by 2 until you reach 0 and look at the remainders.

Printing each remainder

A function that divides by 2 again and again, like you did, and prints each remainder. With end="" it doesn't start a new line: the remainders stay side by side.

Before you run it: what does it print?

def binary(n):    print(n % 2, end="")    if n >= 2:        binary(n // 2)binary(13)

Printing on the way back

The print moved below the call. Now each card calls first and waits; it prints its remainder when the card above returns.

def binary(n):    if n >= 2:        binary(n // 2)    print(n % 2, end="")binary(13)

Output

on the way in (when calling)on the way back (when returning)

The strip fills up on the way in, from left to right. On the way back it prints from right to left: the last card to be called is the first to return.

Returning the binary as text

Printing is good for looking, but sometimes we want to keep the result. This version returns a text: each call joins the text from the card above with its remainder, on the right.

def binary(n):    if n < 2:        return str(n)    return binary(n // 2) + str(n % 2)print(binary(13))

The calculation

Output

The remainders are joined as texts: "110" + "1" is "1101", not 111. That's why each remainder goes through str().

Any base

If you divide by 3 instead of 2, you get the digits in base 3, where each place is worth triple: 1, 3, 9, 27… The function gets the base b as a second parameter.

def to_base(n, b):    if n < b:        return str(n)    return to_base(n // b, b) + str(n % b)print(to_base(13, 2))

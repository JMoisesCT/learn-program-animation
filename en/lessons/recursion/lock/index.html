Cut off branches

The hint comes in as one more parameter: left is what the remaining wheels still have to add up to. If that can't happen anymore, the call returns False without trying anything. Run it without the hint and with the hint.

Each call sets one wheel and leaves the rest to the next call. return True passes the news down, and a hint cuts off whole branches.

secret = "212"

def try_code(n, code, left):
    # the hint: this branch can't work anymore
    if left < 0 or left > 2 * n:
        return False
    # base case: the code is complete
    if n == 0:
        print(code)
        return code == secret
    # this wheel tries 0, 1 and 2
    for d in range(3):
        new = code + str(d)
        if try_code(n - 1, new, left - d):
            # found it! pass the news down
            return True
    # none of them worked
    return False

# 3 wheels, and the digits add up to 5
if try_code(3, "", 5):
    print("Open!")

        How many sevens?

        how_many(n, d) counts how many times the digit d appears in n. Careful: here the base case is n == 0, when there are no digits left.

        def how_many(n, d):
    if n == 0:
        return 0
    elif n % 10 == d:
        return 1 + how_many(n // 10, d)
    else:
        return how_many(n // 10, d)

print(how_many(747, 7))

          Lesson complete!

          To read a recursion, follow the stack: on the way in it goes down to the base case, and on the way back each call finishes its part.

          • Does it have a base case?
          • Does each call get closer to it?
          • Does it return what it computes with return?

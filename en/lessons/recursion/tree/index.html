Add the two before

In this row of numbers, the first two are 0 and 1. Each of the others is the sum of the two right before it.

📜 The number at position n

  1. If n is 0 or 1: the number is n.
  2. If not: add the number at position n − 1 and the one at position n − 2.

Top: the number. Bottom: its position n.

A function that calls itself twice

That row is the Fibonacci sequence. Here is the recipe in Python: fibonacci(n) calls itself twice on the same line. Watch how each card waits.

def fibonacci(n):    if n <= 1:        return n    else:        return fibonacci(n - 1) + fibonacci(n - 2)print(fibonacci(3))

Output

Under line 5 you can read the numbers the running card uses. The orange chips show which call each card waits for: the one on the left or the one on the right.

The call tree

With two calls, the stack goes up and down many times. To see all the calls at once, we draw them as a tree: each call is a circle, and its two calls hang from it.

Now you do the way back

If a function calls itself twice, its calls form a tree. Python goes through it branch by branch, and many calls repeat.

def fibonacci(n):    if n <= 1:        return n  # base case: a leaf    else:        # two branches: first the whole left one,        # then the right one        return fibonacci(n - 1) + fibonacci(n - 2)

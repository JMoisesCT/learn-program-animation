A box inside a box

You got a box as a gift. Inside there is another box, and inside that one, another… Follow the instructions until you find the gift.

📜 How to open a box

  1. Take off the lid.
  2. If there is a candy inside: done!
  3. If there is another box inside: open it with these same instructions.

A function that calls itself

Look at line 6: countdown calls itself, with a smaller number. That is called recursion. Run it and watch the stack.

def countdown(n):    if n == 0:        print("Liftoff!")    else:        print(n)        countdown(n - 1)countdown(3)

Output

on the way in (when calling)on the way back (when returning)

Each call has its own n, on its own card. The if n == 0 is the base case: there the function does not call itself again.

What if there is no base case?

We remove the if. Now the function always calls itself again. When do you think it stops?

def countdown(n):    print(n)    countdown(n - 1)countdown(3)

What open_box(3) does

On the way in and on the way back

Python does not copy the code: it has one recipe and uses the stack to know who called whom. Run it and watch who each call goes back to.

def open_box(n):    if n == 0:        print("A candy!")    else:        print(f"I open box {n}")        open_box(n - 1)        print(f"I close box {n}")open_box(3)

Now you do the way back

open_box(3) again. The three boxes are open and the candy came out: everything on the way in already happened. The stack is full. What now?

A for over the dictionary

In a list, the for gives each value. Here each slot holds two things: key and value. What do you think it will print?

grades = {"Ana": 14, "Luis": 9,          "Eva": 17, "Rosa": 11}for name in grades:    print(name)

With the key, the value

The for gives you the key. For the grade, do what you already know: grades[name] looks up that key and gives you its value.

grades = {"Ana": 14, "Luis": 9,          "Eva": 17, "Rosa": 11}for name in grades:    print(name, grades[name])

Both at once: .items()

.items() gives each pair as a tuple. Just like day, month, year = date, the for unpacks it into two boxes.

grades = {"Ana": 14, "Luis": 9,          "Eva": 17, "Rosa": 11}for name, grade in grades.items():    print(name, "got", grade)

grades.items() → name, grade

Only the values: .values()

To add up the grades you don't need the names. .values() gives only the values, and with them sum and max work just like with a list. Try all six.

grades = {"Ana": 14, "Luis": 9,          "Eva": 17, "Rosa": 11}print(grades.values())

How many passed?

To count who passed (11 or more) only the grades matter: loop over grades.values(). Before you run it, what do you think it will print?

grades = {"Ana": 14, "Luis": 9,          "Eva": 17, "Rosa": 11}count = 0for grade in grades.values():    if grade >= 11:        count += 1print(count)

And whose is the best?

max gives you the grade, but not the name. Find the highest by hand and keep its key too. highest starts at -1, below any grade. You decide: do they change in this round?

grades = {"Ana": 14, "Luis": 9,          "Eva": 17, "Rosa": 11}highest = -1best = ""for name, grade in grades.items():    if grade > highest:        highest = grade        best = nameprint(best, highest)

A dictionary with only the passing grades

Start with an empty dictionary and, in each round, copy the pair only if the grade passes: passed[name] = grade adds the key with its value.

grades = {"Ana": 14, "Luis": 9,          "Eva": 17, "Rosa": 11}passed = {}for name, grade in grades.items():    if grade >= 11:        passed[name] = gradeprint(passed)

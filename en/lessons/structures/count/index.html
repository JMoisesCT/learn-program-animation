The same, with a dictionary

Each name is a key, and its value is how many votes it has. The if asks what you asked: does it already have its slot? Run it.

votes = ["Ana", "Luis", "Ana", "Eva", "Luis"]counts = {}for vote in votes:    if vote in counts:        counts[vote] += 1    else:        counts[vote] = 1print(counts)

The short version: .get()

counts.get(vote, 0) gives what that vote has so far, or 0 if it is not there yet. Add 1 and you are done: one line instead of four.

votes = ["Ana", "Luis", "Ana", "Eva", "Luis"]counts = {}for vote in votes:    counts[vote] = counts.get(vote, 0) + 1print(counts)

Who won?

A text is a row of cells, and each cell has a number: its index. Move the slider and find the first letter and the last one.

Counting from the end

Each cell has another number, a negative one, that counts from the end. Find the last letter and the first one using negative numbers.

Try: 
word = "mango"print(word[-1])
word[-1] → "o"

On top, the index that counts from the start; below, in purple, the one that counts from the end.

The position and the letter

With for letter in word you get each letter, but you don't know which cell it's in. range(len(word)) gives you exactly the indices. Run it.

word = "star"for i in range(len(word)):    print(i, word[i])

How many times does it appear?

.count() counts how many times a piece appears in the text. Count something that appears several times and something that isn’t there.

Try: 
fruit = "banana"print(fruit.count("a"))
fruit.count("a") → 3
Output

Each color is one time the piece appears.

Where is it?

.find() looks for a piece and returns the index of the cell where it starts. Look for something that is there and something that isn’t.

Try: 
email = "ana@web.pe"print(email.find("@"))
email.find("@") → 3
Output

The blue cell checks, from left to right, whether the piece starts there.

Does it start or end like this?

.startswith() checks whether the text starts with a piece, and .endswith(), whether it ends with it. They answer True or False. Get a True with each one, and also a False.

Try: 
file = "beach.jpg"print(file.startswith("beach"))
file.startswith("beach") →
Output

It compares letter by letter: in green, the ones that match; in orange, the ones that don’t.

Is it a number?

input() always gives text. .isdigit() checks that all its characters are digits, before you pass it to int(). Try a number and something that isn’t one.

text = input("Age: ")if text.isdigit():    age = int(text)    print(f"Next year you'll be {age + 1}")else:    print("That's not a number")
Console
Try:
text.isdigit() →

In green, the digits (0 to 9); in orange, what isn’t a digit.

Ask again

If the value is no good, the program can ask for it again: while True asks until a number comes. First type something that isn’t a number.

while True:    text = input("Age: ").strip()    if text.isdigit():        break    print("Type numbers only")age = int(text)print(f"Next year you'll be {age + 1}")

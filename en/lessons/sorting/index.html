Two neighbors in a list

With slots it's the same, and they only swap if they're in the wrong order. Try a j that swaps and one that doesn't.

grades = [14, 9, 17, 11, 6]
j = 2
if grades[j] > grades[j + 1]:
    temp = grades[j]
    grades[j] = grades[j + 1]
    grades[j + 1] = temp

    To sort, the PC compares two neighbors and, if they're in the wrong order, swaps them with a temp box; on each pass, the highest one bubbles up to the end.

    if grades[j] > grades[j + 1]:   # wrong order?
    temp = grades[j]            # 1. keep it safe
    grades[j] = grades[j + 1]   # 2. copy over it
    grades[j + 1] = temp        # 3. put it back
# 5 grades: 4 passes

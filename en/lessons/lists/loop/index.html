Add up all the grades

With a for you visit each slot. If in each round you add the grade to a box total, at the end you have the sum of all of them. Run it.

The highest so far

highest starts with the first grade. In each round, if the grade is bigger, it takes its place. You decide: does highest change in this round?

A list with only the passing grades

Counting tells you how many; sometimes you want which ones. Start with an empty list and, in each round, add the grade only if it passes.

grades = [14, 9, 17, 11, 6]passed = []for grade in grades:    if grade >= 11:        passed.append(grade)print(passed)

Whose grade is it?

With for grade in grades you get the grade, but not whose it is. With range(len(grades)) you go through the indices, and with the same i you read both lists.

students = ["Ana", "Luis", "Sofía", "Iván"]grades = [14, 9, 17, 11]for i in range(len(grades)):    if grades[i] >= 11:        print(students[i], "passed")

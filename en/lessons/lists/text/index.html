Cutting a sentence into words

A text is a row of letters. .split() cuts it at the spaces and puts each word in a slot of a list. Run it, then try a sentence with several spaces in a row.

Try: 
sentence = "it is sunny"words = sentence.split()print(words)

Letters or words?

With .split() it is easy to count the words in a sentence. But look closely at what each one counts.

sentence = "hello to all"

sentence.split()

  1. len(sentence)
  2. len(sentence.split())

Cutting somewhere else

Inside the parentheses of .split() you can say where to cut. We want a clean shopping list: ['jam', 'tea', 'pie']. Which separator gives it?

shopping = "jam, tea, pie"items = shopping.split()print(items)

Cleaning each piece

Sometimes the spaces are uneven and no separator works. Then you cut at the commas and clean each slot with .strip(), one by one. Run it.

data = "jam , tea,pie "items = data.split(",")for i in range(len(items)):    items[i] = items[i].strip()print(items)

Several numbers on one line

      
With input().split() the user types all their grades on one line. But each piece is a text: you have to turn it into a number with int() before adding. Type several grades separated by spaces.

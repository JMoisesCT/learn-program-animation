A whole name in each slot

A list can store text. But watch out: in a text, each cell holds one letter; in a list, each slot holds a whole value.

word = "Ana"

students = ["Ana", "Luis", "Sofía"]

  1. word[1]
  2. students[1]
  3. len(students)

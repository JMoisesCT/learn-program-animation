Fill the list yourself

This is how you save every grade the user types, without knowing how many there will be: the list starts empty and each grade goes in with .append(). Type at least 2 grades and then done.

grades = []while True:    entry = input("Grade: ")    if entry == "done":        break    grades.append(int(entry))print(grades)

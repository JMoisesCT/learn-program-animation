El laberinto

Un ratón robot busca el queso probando caminos y volviendo atrás cuando se mete en un callejón.

★★★★★
  • listas de listas
  • tuplas
  • recursión
  • return True / False
Empezar ↓

1 El caso

En la feria de ciencias, el equipo de robótica armó un laberinto de cartón y un ratón robot. El robot no ve el laberinto desde arriba: solo mira la casilla de al lado.

Si se mete en un callejón, tiene que darse cuenta y volver atrás hasta el último cruce donde le quedaba otro camino. ¿Cómo se escribe «probar y, si falla, volver» sin perderse?

Meta🧀

Problema

Escribe una función buscar(f, c) que diga si desde la casilla (f, c) se puede llegar al queso, moviéndose de una casilla libre a otra vecina (arriba, derecha, abajo o izquierda; sin diagonales).

Entrada

  • lab: una lista de listas, una por fila. Cada casilla es "#" (pared), " " (libre) o "Q" (el queso). El borde es todo pared.
  • La casilla de inicio (f, c): fila y columna de una casilla libre.

Salida

¡Llegué al queso! si hay camino; si no, No hay salida. En lab quedan marcadas con "·" las casillas del camino.

Ejemplos

EntradaSalida
##### # #Q# # # ##### inicio (1, 1)¡Llegué al queso! lab al final: ##### #·#Q# #···# #####
###### # #Q# ###### inicio (1, 1)No hay salida

2 Lo que necesitas saber

Una casilla: lab[f][c]

Una lista de listas: primero la fila, luego la columna. Toca una casilla.

Los cuatro vecinos

Una lista de tuplas guarda cuánto cambian la fila y la columna; el for las desempaqueta.

    3 La idea
    
        
    
          
    
            
    
            
    
              
              
    
              
    Con este laberinto chico: empieza en (2, 1).
    
            
    
          
    
          
    
            
    Una sola función, buscar(f, c), responde «¿desde aquí se llega al queso?». Para contestar, se hace la misma pregunta desde las casillas vecinas.
    
            
      
              
    1. ¿Es el queso? ¡Llegaste! Devuelve True.
      2. 
              
    2. ¿Pared o ya pisada? No sirve Devuelve False sin moverse.
      3. 
              
    3. Deja una miga y prueba los vecinos Si desde alguno se llega, desde aquí también: True.
      4. 
              
    4. Ninguno sirvió: es un callejón Cambia la miga por una x y vuelve con False.
      5. 
            
    
            
    Probar un camino y, si falla, deshacer el último paso y probar otro se llama vuelta atrás (backtracking).

      6 ¿Es el camino más corto?
      
        
      
          
      
            
      No siempre: el ratón se queda con el primer camino que funciona. En «Dos caminos», como prueba arriba primero, subió y dio la vuelta larga.
      
            
      Para encontrar siempre el más corto se usa otra idea: avanzar como una ola, un paso en todas las direcciones a la vez (búsqueda en anchura). La primera vez que la ola toca el queso, ese camino es el más corto.

1 El caso

Ana celebra su cumpleaños en una pollería con Beto, Caro, Dani y Eli. Al final llega la cuenta: 137.50 soles, y quieren dejar 10% de propina.

Beto divide 137.50 entre 5 y dice «27.50 cada uno». Pero se olvidó de la propina: faltan 13.75 soles. ¿Cuánto paga cada uno, con todo incluido?

POLLERÍA · CUENTA

2 pollos a la brasaS/ 96.00
Gaseosas y postreS/ 41.50
ConsumoS/ 137.50

Problema

Escribe un programa que, dado lo que se consumió, el porcentaje de propina y cuántas personas son, diga cuánto es la propina, cuánto es el total y cuánto paga cada uno.

Entrada

  • consumo: lo que se consumió, en soles (puede tener decimales).
  • porcentaje: el porcentaje de propina, un número entero (10 es 10%).
  • personas: cuántos pagan, un entero mayor que 0. Todos pagan lo mismo.

Salida

Tres líneas, con los montos en soles y dos decimales: Propina: S/ …, Total: S/ … y Cada uno paga S/ ….

Ejemplos

EntradaSalida
consumo = 137.50 porcentaje = 10 personas = 5Propina: S/ 13.75 Total: S/ 151.25 Cada uno paga S/ 30.25
consumo = 84 porcentaje = 15 personas = 4Propina: S/ 12.60 Total: S/ 96.60 Cada uno paga S/ 24.15

2 Lo que necesitas saber

Un porcentaje es una fórmula

10% quiere decir 10 de cada 100. Para sacarlo, se multiplica y se divide entre 100.

Cada línea usa las de arriba

Python ejecuta de arriba abajo. Una línea solo puede usar las variables que ya se crearon antes.


              

            

          


          

            
Dos decimales con :.2f

            
Una división puede dar muchos decimales. En la f-string, :.2f escribe solo dos, como se escribe el dinero.

            

              
              
              
            

            

              

              

            

            
:.2f solo cambia cómo se escribe: la variable guarda el número completo.

3 La idea

        

          

            

            

              
              

            

          

          

            
Es lo que haría cualquiera con una calculadora: primero la propina, después el total y al final el reparto. Cada cuenta usa la anterior.

            
    
              
  1. Anota los datos Lo que se consumió, el porcentaje de propina y cuántos son.
    2. 
              
  2. Calcula la propina El porcentaje del consumo: multiplica y divide entre 100.
    3. 
              
  3. Suma y reparte El total es el consumo más la propina; cada uno paga el total entre las personas.
    4. 
              
  4. Muéstralo como dinero Con dos decimales, gracias a :.2f.
    5. 
            

            
Sin decisiones ni vueltas: el programa baja en línea recta y cada línea corre una sola vez.

¿Y si personas es 0?

            
Nadie puede repartir entre cero. Python se detiene en la línea del reparto:

            
  File "cuenta.py", line 6, in <module>
    cada_uno = total / personas
               ~~~~~~^~~~~~~~~~
ZeroDivisionError: float division by zero

            
En cambio, porcentaje = 0 sí funciona: imprime Propina: S/ 0.00. El enunciado pide personas mayor que 0; un programa más cuidadoso lo revisaría antes con un if.

6 ¿Siempre cierra la cuenta?

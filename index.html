Aprende a programar

Lecciones cortas e interactivas con Python. Toca, mueve y prueba: así se entiende cómo piensa un programa.

  • 📦

    Variables

    Cajas con nombre para guardar datos, calcular con ellos y escribir mensajes.

    Ver las lecciones
    1. ¿Qué es una variable? Cajas con nombre que guardan un valor.
    2. Fórmulas Calcular con variables: operadores, paréntesis, // y %.
    3. Reúso Usar una variable en muchos lugares y actualizarla: x = x + 1 y +=.
    4. Texto y números "5" + "5" da "55": tipos int y str, int(), str() e input().
    5. Mensajes con f-strings print(f"Hola {nombre}"): valores dentro del texto, cuentas y decimales con :.2f.

    Condicionales

    Decidir qué hacer según una condición y combinar varias preguntas en una.

    Ver las lecciones
    1. if, else y elif Preguntas de sí o no, los seis comparadores y elegir un camino.
    2. Combinar condiciones and, or y not: varias preguntas en una, y valores entre dos números.
    3. Comparar textos Mayúsculas, .lower(), buscar con in y comparar lo que llega de input().
    4. Condiciones anidadas Un if dentro de otro: árboles de decisiones, la sangría y cuándo juntarlos con and.
    5. Proyecto: la taquilla Programa por partes una taquilla de cine que pregunta, decide el precio y responde.

    Bucles

    Repetir una tarea sin escribirla mil veces: contar, sumar, decidir en cada vuelta, recorrer textos, salir a tiempo, anidar bucles y dibujar patrones.

    Ver las lecciones
    1. for, range y while Repetir sin copiar y pegar: una vuelta por cada número o mientras algo sea True.
    2. Contar y acumular range con salto, cuentas regresivas, contadores y acumuladores con +=.
    3. Decidir en cada vuelta Un if dentro del bucle: filtrar, par o impar, contar los que cumplen y buscar el récord.
    4. Recorrer un texto for letra in "hola": una vuelta por letra, contar vocales y medir con len().
    5. Salir antes: break y continue Cortar el bucle, saltarse una vuelta, while True y cómo evitar bucles infinitos.
    6. Bucles anidados Un bucle dentro de otro: cuadrículas, tablas de multiplicar y escaleras de estrellas.
    7. Dibujar patrones ¿i o j?, espacios para alinear, pirámides, cuadrado vacío y tablero de ajedrez.
    8. Proyecto: adivina el número Programa por partes un juego que piensa un número y te da pistas hasta que lo aciertas.

    Funciones

    Recetas con nombre que puedes reutilizar: def, parámetros, return, las funciones que Python ya trae hechas, funciones que usan otras y un juego hecho con funciones.

    Ver las lecciones
    1. def, parámetros y return Una receta con nombre: se define una vez, se llama cuando quieras y te devuelve un valor.
    2. Ya las usabas: funciones de Python input, len, int, str, round, abs, max y random.randint: entra un valor y sale otro, también una dentro de otra.
    3. Varios parámetros Repartir argumentos por posición o por nombre, y parámetros con valor por defecto.
    4. Funciones que deciden Un return en cada camino del if, funciones que devuelven True o False, y por qué sin return sale None.
    5. Variables locales Las cajas de una función nacen al llamarla y se borran al volver; el mismo nombre dentro y fuera son cajas distintas.
    6. Funciones que usan funciones Una función que llama a otra, bucles dentro de una función y la pila de llamadas: cada return quita la tarjeta de arriba.
    7. Proyecto: piedra, papel o tijera Programa por partes el juego contra la computadora: tres funciones pequeñas y un bucle con marcador.

    Recursión

    Funciones que se llaman a sí mismas: como abrir una caja que tiene otra caja dentro.

    Ver las lecciones
    1. Una función que se llama a sí misma El caso base, la pila que crece y se vacía, el RecursionError y lo que se hace a la ida y a la vuelta.
    2. Recursión que devuelve valores factorial, potencia y suma de dígitos: lo que devuelve cada llamada baja a la de abajo y completa su cuenta.
    3. Árbol de llamadas fibonacci se llama dos veces: el árbol que crece rama por rama, las llamadas que se repiten y cuántas hace en total.
    4. Proyecto: Torres de Hanói Mueve los discos a mano, descubre la idea y escribe hanoi(n, origen, destino, auxiliar), que los mueve sola.

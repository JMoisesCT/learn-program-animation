Letra a letra

Un for también recorre un texto: da una vuelta por cada letra. Escribe una palabra y recórrela.

palabra = "hola"for letra in palabra:    print(letra)
    letra
    Vueltas: 0
    Salida

    Contar las vocales

    En cada vuelta, un if pregunta si la letra es una vocal. Si lo es, el contador sube. Ejecútalo.

    "banana"

    1. b
    2. a
    3. n
    4. a
    5. n
    6. a
    letra in "aeiou" → False
    letra
    vocales 
    vocales = 0for letra in "banana":    if letra in "aeiou":        vocales += 1print(f"Tiene {vocales} vocales")

    Salida

    ¿Cuántas letras tiene?

    len() cuenta los caracteres de un texto. Añade un espacio y otra palabra: ¿el espacio cuenta?

    texto = "hola"print(len(texto))

      Salida

      for letra in texto da tantas vueltas como dice len(texto): una por carácter.

      Las vocales de tu palabra

      Ahora la palabra la escribes tú. .lower() la pasa a minúsculas, así una «A» también cuenta.

      palabra = input("Palabra: ")vocales = 0for letra in palabra.lower():    if letra in "aeiou":        vocales += 1print(f"{len(palabra)} letras, {vocales} vocales")

        vocales

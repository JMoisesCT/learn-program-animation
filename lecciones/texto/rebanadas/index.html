Texto a fondo 2/5 · Rebanadas

Corta un pedazo

Una rebanada se lleva un pedazo del texto. Arrastra las tijeras (o tócalas y usa las flechas) y saca «sol» y «gira» de «girasol».

palabra = "girasol"print(palabra[1:4])
  • "sol"
  • "gira"
palabra[1:4] → "ira"
Salida

El final no entra

Los números van en los cortes, no en las letras. ¿Qué sale en cada caso?

palabra = "girasol"

  1. palabra[2:6]
  2. palabra[3:3]
  3. palabra[5:50]

Desde el principio, hasta el final

Si no pones el inicio, la rebanada empieza en el principio; si no pones el fin, llega hasta el final. Quita cada uno, por turnos.

palabra = "girasol"print(palabra[0:4])
palabra[0:4] → "gira"
Salida

Las últimas letras

Queremos la extensión de un archivo: png, pdf… Los nombres miden distinto. ¿Qué rebanada sirve para los tres?

archivo = "tarea.pdf"print(archivo[?])

    Abajo, en morado, el número negativo de cada corte: -3 es el corte antes de las 3 últimas letras.

    Partir una fecha

    De "21/10/2026" ya sacamos el día. Ahora usa las tijeras para sacar el mes y después el año.

    fecha = "21/10/2026"dia = fecha[0:2]mes = fecha[?]año = fecha[?]print(f"Mes {mes} del año {año}")

    Corta el mes.

    "21"
    dia
    mes
    año

    ¿Qué imprime?

    Dos rebanadas de la misma palabra, pegadas con +.

    palabra = "programa"print(palabra[3:] + palabra[:3])
    ¿Qué imprime?

    ↓ palabra[3:] + palabra[:3]

    texto[inicio:fin] se lleva lo que hay entre dos cortes: el fin no entra, y si falta un número, llega hasta el borde.

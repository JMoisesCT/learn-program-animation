if: solo si es True

Elige un color. El código de dentro del if solo se ejecuta si la condición es True.

🚶
"rojo" == "verde" → False 
semaforo = "rojo"if semaforo == "verde":    print("¡Puedes cruzar!")
Salida

Los 4 espacios al inicio dicen qué líneas están dentro del if. Y ojo: == pregunta «¿es igual?», = guarda un valor.

else: el plan B

Con else siempre pasa algo: si la condición es False, se va por el otro camino. Prueba temperaturas distintas.

18 > 25 → False
🧢 if → True
🧥 else → False 
temperatura = 18if temperatura > 25:    print("Ponte gorra")else:    print("Lleva chaqueta")
Salida

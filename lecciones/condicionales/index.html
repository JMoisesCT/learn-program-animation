Seis maneras de comparar

Las seis preguntas miran los mismos dos números. Haz que a sea menor, igual y mayor que b.

a = 3b = 7

    Ojo: == pregunta «¿es igual?» y != pregunta «¿es distinto?».

    if: solo si es True

    Elige un color. El código de dentro del if solo se ejecuta si la condición es True.

    🚶
    "rojo" == "verde" → False 
    semaforo = "rojo"if semaforo == "verde":    print("¡Puedes cruzar!")
    Salida

    Los 4 espacios al inicio dicen qué líneas están dentro del if. Y ojo: == pregunta «¿es igual?», = guarda un valor.

    else: el plan B

    Con else siempre pasa algo: si la condición es False, se va por el otro camino. Prueba temperaturas distintas.

    18 > 25 → False
    🧢 if → True
    🧥 else → False 
    temperatura = 18if temperatura > 25:    print("Ponte gorra")else:    print("Lleva chaqueta")
    Salida

    ¿Par o impar?

    Reparte n fichas en parejas: si no sobra ninguna, el número es par. En Python, n % 2 es lo que sobra.

    n = 7if n % 2 == 0:    print("Es par")else:    print("Es impar")

    Sobra 1

    7 % 2 == 0 → 1 == 0 → False
    Salida

Un trapecista con red

Alguien escribe «quince» y int() falla. Un trapecista practica con una red: si se cae, la red lo atrapa y el show sigue. En Python, la red es try y except. Prueba sin red y con red.

¿Qué imprime?

      
El mismo programa con tres datos. Fíjate en lo que pasa antes de la línea que falla.

    Cada red, su tipo
    
      
    Aquí pueden fallar dos cosas: que no escriban un número o que escriban 0. Prueba los tres datos. ¿La red atrapa todo?
    

      
    
        
    
          
    
            Escribe:
            
            
            
          
    
          
    
          
    try: la zona protegidaexcept: la red
    
          
    
            
            
            
          
    
        
    
        
    
          
    
          
    Salida
    
          
    
          
    
        
    
      
    
    
    

    
    
    
      
    Una red para cada error
    
      
    Puede haber varios except, uno por tipo. El error prueba red por red, de arriba abajo. Prueba con «tres» y con «0».
    

      
    
        
    
          
    
            Escribe:
            
            
            
          
    
          
    
          
    try: la zona protegidaexcept: las redes
    
          
    
            
            
            
          
    
        
    
        
    
          
    
          
    Salida

    La trampa: except: sin tipo
    
      
    Este programa tiene un nombre mal escrito. Se ejecuta con «15», que sí es un número. Compara una red sin tipo con una red ValueError.

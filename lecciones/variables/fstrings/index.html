Un texto con huecos

Las llaves { } son huecos dentro del texto. Ejecuta el código y mira qué cae en cada uno.

nombre = "Ana"edad = 12print(f"{nombre} tiene {edad} años")

nombre
edad
f{nombre} tiene {edad} años
Salida

Adiós a tanto +

Así lo hacíamos en la lección anterior. Pulsa el botón para convertirlo en una f-string.

nombre = "Ana"edad = 12print(f"{nombre + "} tiene " + str({edad) + "} años")
  • 3signos +
  • 1str()
  • 4comillas
Salida

Cambia los valores

Escribe tu nombre y mueve la edad. Los huecos se rellenan solos.

Cuentas dentro de las llaves

En un hueco cabe una fórmula entera. Mueve cuántas entradas de cine compras.

precio = 6cantidad = 3print(f"{cantidad} entradas: {precio * cantidad} soles")
f entradas: soles
Salida

Dos decimales con :.2f

Una cuenta de 20 soles entre amigos. Mueve cuántos sois y compara las dos líneas de la salida.

cuenta = 20personas = 3pago = cuenta / personasprint(f"Cada uno paga {pago}")print(f"Cada uno paga {pago:.2f}")
  • : dar formato
  • .2 dos decimales
  • f número con decimales
{pago}
↓ :.2f
{pago:.2f}

    Una matriz guarda la sala: sala[f][c] es un asiento, dos for la recorren, y el try y las orillas cuidan lo que escribe el cliente.

    • sala[f][c]
    • "ABCDE"[f]
    • " ".join(fila)
    • return True / False
    • try / except ValueError
    • f == -1 or c >= 8
    • for fila in sala
    • return f, c
    • while True / break

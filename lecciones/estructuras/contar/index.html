La versión corta: .get()

conteo.get(voto, 0) da lo que lleva ese voto, o 0 si todavía no está. Le sumas 1 y listo: una línea en vez de cuatro.

votos = ["Ana", "Luis", "Ana", "Eva", "Luis"]conteo = {}for voto in votos:    conteo[voto] = conteo.get(voto, 0) + 1print(conteo)

¿Quién ganó?

Para saber cuál se repitió más, busca la mayor como en la lección anterior, guardando también la clave. Tú decides: ¿cambia ganador en esta vuelta?

conteo = {"Ana": 3, "Luis": 5, "Eva": 5}ganador = ""mas = 0for nombre, n in conteo.items():    if n > mas:        mas = n        ganador = nombreprint(ganador, mas)

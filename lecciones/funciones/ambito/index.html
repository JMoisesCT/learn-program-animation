Funciones 5/7 · Variables locales

Cajas que nacen y desaparecen

Cada llamada abre su propia zona de cajas. Al volver con return, la zona se borra. Ejecútalo y mira las dos zonas.

def total(precio, cantidad):    suma = precio * cantidad    return sumapagar = total(5, 3)print(pagar)

Salida

Las variables de dentro de una función se llaman locales: solo existen mientras la función se ejecuta.

Desde fuera no se ven

¿Y si después de la llamada intentamos imprimir suma? Prueba las dos últimas líneas.

def total(precio, cantidad):    suma = precio * cantidad    return sumapagar = total(5, 3)print(pagar)

Salida

Mismo nombre, cajas distintas

Hay una x fuera y otra x dentro de la función. Si cambias la de dentro, ¿cambia la de fuera? Ejecútalo línea a línea.

def cambiar(x):    x = 100    print(f"dentro: {x}")x = 5cambiar(x)print(f"fuera: {x}")

Salida

Para sacar un valor, return

Queremos sumar un punto. La versión 1 cambia la caja de dentro; la versión 2 devuelve el resultado. Ejecuta las dos.

def subir(puntos):puntos = 10print(puntos)

Salida
Reto

¿Qué imprime?

Piensa en las dos zonas de cajas: la del programa y la de la función.

def subir(nota):    extra = 2    nota = nota + extra    return notanota = 12nueva = subir(nota)print(nueva)print(nota)

Las variables de una función nacen al llamarla y se borran al volver: lo de dentro se queda dentro. Para sacar un valor, usa return.

def total(precio, cantidad):    # suma vive solo aquí    suma = precio * cantidad    return sumapagar = total(5, 3)print(pagar)  # 15print(suma)   # NameError

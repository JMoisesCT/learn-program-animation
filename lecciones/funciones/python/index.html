Una función dentro de otra

Lo que devuelve una función puede ser el argumento de otra. Python calcula primero la de dentro. Resuelve dos.

Una función con sorpresa

random.randint(1, 6) devuelve un número al azar entre 1 y 6, los dos incluidos. Ejecútalo varias veces.

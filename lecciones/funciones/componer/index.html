    ¿De cuántas formas?

    ¿De cuántas formas puedes ordenar unos libros en una repisa? Se multiplica 1 × 2 × 3 × … hasta el número de libros. Eso es el factorial, y una función con un for lo calcula.

    def factorial(n):    resultado = 1    for i in range(1, n + 1):        resultado *= i    return resultadoformas = factorial(4)print(f"{formas} formas")

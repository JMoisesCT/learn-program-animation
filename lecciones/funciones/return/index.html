Una función con varias salidas

Dentro de una función puedes usar if y elif, y poner un return en cada camino. Mueve la nota y encuentra las tres salidas.

def calificar(nota):    if nota >= 18:        return "Excelente"    elif nota >= 11:        return "Aprobado"    else:        return "Desaprobado"print(calificar(15))
    calificar(15) → "Aprobado"
    Salida
    • "Excelente"
    • "Aprobado"
    • "Desaprobado"

    return termina la función

    Cuando Python llega a un return, entrega el valor y sale de la función en ese mismo instante. ¿Se imprimirá «¡Bien hecho!»? Ejecútalo con las dos notas.

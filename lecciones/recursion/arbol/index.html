Sumar los dos anteriores

En esta fila de números, los dos primeros son 0 y 1. Cada uno de los demás es la suma de los dos que tiene antes.

📜 El número de la posición n

  1. Si n es 0 o 1: el número es n.
  2. Si no: suma el número de la posición n − 1 y el de la posición n − 2.

Una función que se llama dos veces

Esa fila se llama serie de Fibonacci. La receta, en Python: fibonacci(n) se llama a sí misma dos veces en la misma línea. Mira cómo espera cada tarjeta.

def fibonacci(n):    if n <= 1:        return n    else:        return fibonacci(n - 1) + fibonacci(n - 2)print(fibonacci(3))

Salida

La tarjeta espera dos veces en la línea 5: primero con ▢ + fibonacci(…) y luego, con la primera parte ya puesta, con … + ▢.

El árbol de llamadas

Con dos llamadas, la pila sube y baja muchas veces. Para ver todas las llamadas a la vez, se dibujan como un árbol: cada llamada es un círculo, y sus dos llamadas cuelgan de él.

def fibonacci(n):    if n <= 1:        return n    else:        return fibonacci(n - 1) + fibonacci(n - 2)print(fibonacci(4))

Si una función se llama dos veces, sus llamadas forman un árbol. Python lo recorre rama por rama, y muchas llamadas se repiten.

def fibonacci(n):    if n <= 1:        return n  # caso base: una hoja    else:        # dos ramas: primero toda la de la izquierda,        # luego la de la derecha        return fibonacci(n - 1) + fibonacci(n - 2)

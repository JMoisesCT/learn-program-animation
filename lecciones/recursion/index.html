Una caja dentro de otra

Te regalaron una caja. Dentro hay otra caja, y dentro otra más… Sigue las instrucciones hasta encontrar el regalo.

📜 Cómo abrir una caja

  1. Quítale la tapa.
  2. Si dentro hay un caramelo: ¡listo!
  3. Si dentro hay otra caja: ábrela con estas mismas instrucciones.

Una función que se llama a sí misma

Mira la línea 6: cuenta_regresiva se llama a sí misma, con un número más pequeño. A eso se le llama recursión. Ejecútala y mira la pila.

def cuenta_regresiva(n):    if n == 0:        print("¡Despegue!")    else:        print(n)        cuenta_regresiva(n - 1)cuenta_regresiva(3)

Salida

a la ida (al llamar)a la vuelta (al volver)

Cada llamada tiene su propia n, en su propia tarjeta. El if n == 0 es el caso base: ahí la función ya no se llama otra vez.

¿Y si no hay caso base?

Quitamos el if. Ahora la función siempre vuelve a llamarse. ¿Cuándo crees que para?

A la ida y a la vuelta

Volvamos a las cajas: abrir(n) abre la caja n. Ahora hay un print antes de la llamada y otro después.

Antes de ejecutar: ¿qué se imprime justo después de «¡Un caramelo!»?

def abrir(n):    if n == 0:        print("¡Un caramelo!")    else:        print(f"Abro la caja {n}")        abrir(n - 1)        print(f"Cierro la caja {n}")abrir(3)

Ahora la vuelta la haces tú

Otra vez abrir(3). Ya se abrieron las tres cajas y salió el caramelo: todo lo de la ida ya pasó. La pila está llena. ¿Y ahora?

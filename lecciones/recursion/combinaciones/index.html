Cara o sello

Lanzas 3 monedas, una tras otra. Cada una sale cara (C) o sello (S). ¿De cuántas formas distintas pueden salir? Encuéntralas todas.

  1. ?moneda 1
  2. ?moneda 2
  3. ?moneda 3

Cada moneda parte el camino en dos. Abajo, cada hoja es una forma de salir.

Encontradas: 0

    Una función que lanza monedas

    En Python: n son las monedas que faltan y tiros, lo que ya salió. Si no falta ninguna, imprime. Si no, prueba las dos: primero cara y luego sello, con una llamada para cada una.

    def lanzar(n, tiros):    if n == 0:        print(tiros)    else:        lanzar(n - 1, tiros + "C")        lanzar(n - 1, tiros + "S")lanzar(2, "")

    Salida

    Bajo la línea de cada llamada se lee con qué valores la hace la tarjeta que corre: tiros con una letra más.

    El árbol de decisiones

    Cada llamada es un círculo, con su tiros adentro. Sus dos llamadas cuelgan de él: la rama C y la rama S. Mira cómo crece con lanzar(3, "").

    def lanzar(n, tiros):    if n == 0:        print(tiros)    else:        lanzar(n - 1, tiros + "C")        lanzar(n - 1, tiros + "S")lanzar(3, "")

    Salida

    A la izquierda, cuántas monedas faltan en cada piso (n). Las letras de las ramas, de arriba abajo, forman tiros.

    ¿Cuántas salen?

    Con 3 monedas salieron 8 combinaciones. ¿Y con otras cantidades? Predice antes de ver el árbol.

      Tres opciones por vuelta

      Piedra, papel o tijera, en 2 rondas. En cada ronda hay tres jugadas posibles, así que la función se llama tres veces.

      def jugar(n, jugadas):    if n == 0:        print(jugadas)    else:        jugar(n - 1, jugadas + "✊")        jugar(n - 1, jugadas + "✋")        jugar(n - 1, jugadas + "✌️")jugar(2, "")

      ¿Cuántas líneas imprime jugar(2, "")?

      Sin dos sellos seguidos

      Una regla nueva: no valen las combinaciones con dos sellos seguidos (SS). Toca en el árbol las hojas que sobran.

      Tachadas: 0

      Podar ramas

      Para cortar a tiempo, cada llamada tiene que saber qué salió la última vez. Se lo pasamos en otro parámetro: ultima. Si fue sello, no prueba otro sello: esa rama ni se empieza.

      def lanzar(n, tiros, ultima):    if n == 0:        print(tiros)    else:        lanzar(n - 1, tiros + "C", "C")        if ultima != "S":            lanzar(n - 1, tiros + "S", "S")lanzar(3, "", "")

      Llamadas: 0 corre imprimió cortada ✂
      Salida

      Sin índices, la función no puede mirar la última letra de tiros: por eso la recuerda aparte, en ultima.

      Reto

      Subir la escalera

      Una escalera de 4 escalones. Puedes subir de 1 en 1 o de 2 en 2. Completa escalera(falta, camino) para que imprima todas las formas de subirla, y di cuántas son.

      def escalera(falta, camino):    if ▢ 1:        print(camino)    if falta >= 1:        escalera(falta - 1, camino + "1")    if ▢ 2:        escalera(falta - 2, camino + "2")escalera(4, "")

      Un camino: 1, 1 y 2. Python lo imprime como 112.

      Cada rama sube 1 o 2. Las cortadas (✂) se pasarían del último escalón.

      Salida
      🎉

      ¡Lección completada!

      Una llamada por cada opción, con lo elegido en un parámetro: cada hoja del árbol imprime una combinación.

      def lanzar(n, tiros):    if n == 0:        print(tiros)  # una hoja    else:        # una rama por opción;        # un if puede podar una        lanzar(n - 1, tiros + "C")        lanzar(n - 1, tiros + "S")

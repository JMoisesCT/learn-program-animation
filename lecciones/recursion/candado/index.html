Cortar ramas

La pista entra como un parámetro más: falta es lo que les falta sumar a las ruedas que quedan. Si ya no se puede cumplir, la llamada devuelve False sin probar nada. Ejecútalo sin pista y con pista.

secreta = ⟨p7-secreta|"212"⟩

def probar(n, clave, falta):
    if falta < 0 or falta > 2 * n:
        return False
    if n == 0:
        print(clave)
        return clave == secreta
    for d in range(3):
        nueva = clave + str(d)
        if probar(n - 1, nueva, falta - d):
            return True
    return False

if probar(3, "", 5):
    print("¡Abierto!")

falta < 0: ya se pasó. falta > 2 * n: aunque las n ruedas que quedan marquen 2, no llegan.

Cada llamada fija una rueda y deja las demás a la siguiente. return True avisa hacia abajo, y una pista corta ramas enteras.

secreta = "212"

def probar(n, clave, falta):
    # la pista: esta rama ya no puede cumplirse
    if falta < 0 or falta > 2 * n:
        return False
    # caso base: la clave está completa
    if n == 0:
        print(clave)
        return clave == secreta
    # esta rueda prueba 0, 1 y 2
    for d in range(3):
        nueva = clave + str(d)
        if probar(n - 1, nueva, falta - d):
            # ¡la encontró! avisa hacia abajo
            return True
    # ninguna sirvió
    return False

# 3 ruedas, y los dígitos suman 5
if probar(3, "", 5):
    print("¡Abierto!")

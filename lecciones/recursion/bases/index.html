Recursión 3/7 · Dígitos y bases

¿Cuántos dígitos tiene?

Tú ves de un vistazo que 4071 tiene 4 dígitos. Python no los ve: para él es un número. Pero sí puede dividir: 4071 // 10 da 407, el número sin su último dígito.

Número:

📜 Cómo contar los dígitos de n

  1. Si tiene un solo dígito (n < 10): tiene 1.
  2. Si no: córtale el último (n // 10), cuenta los dígitos de lo que queda y súmale 1.

El número n

Los que se fueron (n % 10)

Un dígito menos en cada llamada

La receta, en Python. Cada llamada recibe el número con un dígito menos, hasta que queda uno solo: el caso base.

Número: 
def contar_digitos(n):    if n < 10:        return 1    return 1 + contar_digitos(n // 10)print(contar_digitos(4071))

La cuenta

Salida

Mira el título de cada tarjeta: el número pierde su último dígito en cada llamada. Cada tarjeta que espera guarda 1 + ▢: suma 1 a lo que le devuelva la de arriba.

Solo ceros y unos

La computadora guarda los números en binario: solo con 0 y 1. Cada lugar vale el doble que el de su derecha: 1, 2, 4, 8… (en el sistema de siempre, cada lugar vale 10 veces más: 1, 10, 100…).

Los restos de dividir entre 2

¿Cómo pasa Python un número a binario? Igual que % 10 daba el último dígito de siempre, % 2 da el último dígito en binario. Divide entre 2 hasta llegar a 0 y mira los restos.

Número:

El número n

Restos (n % 2), en el orden en que salen

En binario

Imprimir cada resto

Una función que divide entre 2 una y otra vez, como tú, e imprime cada resto. Con end="" no salta de línea: los restos quedan uno al lado del otro.

Antes de ejecutar: ¿qué imprime?

def binario(n):    print(n % 2, end="")    if n >= 2:        binario(n // 2)binario(13)

Restos (n % 2) de cada llamada

Salida

a la ida (al llamar)a la vuelta (al volver)

13 en binario es 1101. ¿Qué cambiarías para que salga en orden?

Imprimir a la vuelta

El print bajó debajo de la llamada. Ahora cada tarjeta llama primero y espera; imprime su resto cuando vuelve la de arriba.

def binario(n):    if n >= 2:        binario(n // 2)    print(n % 2, end="")binario(13)

Restos (n % 2) de cada llamada

Salida

a la ida (al llamar)a la vuelta (al volver)

La tira se llena a la ida, de izquierda a derecha. A la vuelta se imprime de derecha a izquierda: la última tarjeta en llamarse es la primera en volver.

Devolver el binario como texto

Imprimir sirve para mirar, pero a veces queremos guardar el resultado. Esta versión devuelve un texto: cada llamada une el texto de la de arriba con su resto, a la derecha.

def binario(n):    if n < 2:        return str(n)    return binario(n // 2) + str(n % 2)print(binario(13))

La cuenta

Salida

Los restos se unen como textos: "110" + "1" es "1101", no 111. Por eso cada resto pasa por str().

Cualquier base

Si en vez de 2 divides entre 3, salen los dígitos en base 3, donde cada lugar vale el triple: 1, 3, 9, 27… La función recibe la base b como segundo parámetro.

def a_base(n, b):    if n < b:        return str(n)    return a_base(n // b, b) + str(n % b)print(a_base(13, 2))

a_base(13, 2) devuelve"1101"

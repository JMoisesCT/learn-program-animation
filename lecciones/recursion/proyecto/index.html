Proyecto: Torres de Hanói

Lleva la torre de discos de A a C. Parece fácil, pero hay reglas.

  1. Mueve un disco a la vez.
  2. Solo se mueve el disco de arriba de una torre.
  3. Nunca pongas un disco sobre otro más chico.

Toca una torre para levantar su disco de arriba y otra para dejarlo. También puedes arrastrarlo.

Movimientos: 0

¿Dónde tienen que estar el 1 y el 2 justo antes de mover el 3?

Parte 2 de 3

Tres pasos grandes

Ahora son 4 discos. Usa la misma idea: cada botón hace un paso grande. Elige el orden.

Movimientos: 0

📜 Para mover n discos de origen a destino

  1. Si n es 1: mueve ese disco y listo.
  2. Si no: mueve n − 1 discos de origen al auxiliar…
  3. …mueve el disco n de origen a destino…
  4. …y mueve los n − 1 discos del auxiliar al destino.
Parte 3 de 3

La función hanoi

La receta, en Python. Mover n - 1 discos es llamar a hanoi otra vez, con las torres en otros papeles. Elige qué va en cada espacio en blanco.

def hanoi(n, origen, destino, auxiliar):    if n == 1:        print(f"Disco 1: {origen} → {destino}")    else:        hanoi(n - 1, ▢ 1)        print(f"Disco {n}: {origen} → {destino}")        hanoi(n - 1, ▢ 2)hanoi(3, "A", "C", "B")

Recuerda el orden de los parámetros: hanoi(n, origen, destino, auxiliar).

Un problema grande se resuelve con el mismo problema más pequeño: para mover n discos, mueve n − 1, el grande y otra vez n − 1.

def hanoi(n, origen, destino, auxiliar):    if n == 1:  # caso base        print(f"Disco 1: {origen} → {destino}")    else:        # los de arriba, al auxiliar        hanoi(n - 1, origen, auxiliar, destino)        # el grande, a su lugar        print(f"Disco {n}: {origen} → {destino}")        # y los de arriba, encima        hanoi(n - 1, auxiliar, destino, origen)

        ¿Cuántos sietes?

        cuantos(n, d) cuenta cuántas veces aparece el dígito d en n. Ojo: aquí el caso base es n == 0, cuando ya no quedan dígitos.

        def cuantos(n, d):
    if n == 0:
        return 0
    elif n % 10 == d:
        return 1 + cuantos(n // 10, d)
    else:
        return cuantos(n // 10, d)

print(cuantos(747, 7))

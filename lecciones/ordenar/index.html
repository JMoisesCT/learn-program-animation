Ordena con tus manos

sorted(notas) ordena una lista en una línea. Pero ¿cómo lo hace la PC, si solo puede comparar dos valores a la vez? Hazlo tú así: ordena de menor a mayor intercambiando vecinos.

Intercambiar dos variables

La PC intercambia valores guardados en variables. Para intercambiar a y b, alguien escribió esto. Antes de ejecutarlo, ¿qué imprime?

b = 9

Una tercera caja

Para cambiar el jugo y la leche de dos vasos, necesitas un tercer vaso vacío. En el código, ese vaso es otra variable: aux (de «auxiliar»). Ejecútalo.

a = 14
b = 9
aux = a
a = b
b = aux
print(a, b)

Dos vecinos de una lista

Con casilleros es igual, y solo se intercambian si están al revés. Prueba un j que intercambie y otro que no.

notas = [14, 9, 17, 11, 6]
j = 2
if notas[j] > notas[j + 1]:
    aux = notas[j]
    notas[j] = notas[j + 1]
    notas[j + 1] = aux
print(notas)

    Para ordenar, la PC compara dos vecinos y, si están al revés, los intercambia con una caja aux; en cada pasada, la mayor sube hasta el final.

    if notas[j] > notas[j + 1]:   # ¿al revés?
    aux = notas[j]            # 1. a salvo
    notas[j] = notas[j + 1]   # 2. copiar encima
    notas[j + 1] = aux        # 3. devolver
# 5 notas: 4 pasadas

Sumar todas las notas

Con un for pasas por cada casillero. Si en cada vuelta sumas la nota a una caja total, al final tienes la suma de todas. Ejecútalo.

notas = [14, 9, 17, 11, 6]total = 0for nota in notas:    total = total + notaprint(total)

¿Cuántos aprobaron?

Ahora el for no suma la nota: suma 1 solo cuando la nota aprueba (11 o más). Antes de ejecutarlo, ¿cuánto crees que imprimirá?

notas = [14, 9, 17, 11, 6]cuantos = 0for nota in notas:    if nota >= 11:        cuantos = cuantos + 1print(cuantos)

La mayor hasta ahora

mayor empieza con la primera nota. En cada vuelta, si la nota es más grande, ocupa su lugar. Tú decides: ¿cambia mayor en esta vuelta?

notas = [12, 9, 17, 11, 18, 6]mayor = notas[0]for nota in notas:    if nota > mayor:        mayor = notaprint(mayor)

¿De quién es la nota?

Con for nota in notas tienes la nota, pero no sabes de quién es. Con range(len(notas)) recorres los índices, y con el mismo i lees las dos listas.

alumnos = ["Ana", "Luis", "Sofía", "Iván"]notas = [14, 9, 17, 11]for i in range(len(notas)):    if notas[i] >= 11:        print(alumnos[i], "aprobó")

Cinco notas, cinco variables

Para guardar las notas de 5 alumnos usamos 5 cajas. ¿Y si fueran 40? Hay una forma mejor: una sola variable con todas las notas, en orden. Toca el botón.

nota1 = 14nota2 = 9nota3 = 17nota4 = 11nota5 = 6

5 variables

Cada casillero tiene su número

Como en un texto, cada elemento de la lista tiene su índice, y se cuenta desde 0. Mueve el control y busca la primera nota y la última.

notas = [14, 9, 17, 11, 6]print(notas[2])
notas[2] → 17

Un nombre entero en cada casillero

Una lista puede guardar textos. Pero ojo: en un texto, cada casilla tiene una letra; en una lista, cada casillero tiene un valor entero.

palabra = "Ana"

alumnos = ["Ana", "Luis", "Sofía"]

  1. palabra[1]
  2. alumnos[1]
  3. len(alumnos)
